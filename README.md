# UNREConnect - Alumni Portal System

## Overview
UNREConnect is a comprehensive alumni management system designed to connect graduates, facilitate networking, and support career development. The platform includes features for alumni profiles, job postings, mentorship programs, event management, and donation processing.

## Key Features
- **Alumni Directory**: Search and connect with fellow graduates
- **Career Services**: Job postings and application management
- **Mentorship Program**: Connect with mentors/mentees
- **Event Management**: Create and manage alumni events
- **Discussion Forums**: Engage in community discussions
- **Donation System**: Support university initiatives
- **Admin Dashboard**: Comprehensive system administration

## Technical Stack
- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap
- **Backend**: PHP, MySQL
- **Libraries**: PHPMailer, Monolog
- **Version Control**: Git

## Installation
1. Clone the repository
2. Import the database schema from `database/schema.sql`
3. Configure database connection in `config.php`
4. Set up web server (Apache/Nginx) with PHP 7.4+
5. Configure SMTP settings for email functionality

## Configuration
- Update database credentials in `config.php`
- Configure email settings in `admin/configure_email.php`
- Set up cron jobs for scheduled tasks
